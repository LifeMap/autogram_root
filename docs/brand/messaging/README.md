## 📊 핵심 수치 요약

### 베타 기간 (현재 ~ Meta 승인)
- **목표**: 베타 테스터 100~150명
- **예산**: $60~110 (3개월)
- **KPI**: NPS 40+, 활성 사용자 50~100명

### Month 1~3 (정식 런칭 ~ 초기 성장)
- **목표**: 700 MAU, NPS 50+
- **예산**: $50~100/월
- **채널**: Instagram, 카페, 블로그 (오가닉 중심)

### Month 4~6 (스케일 업)
- **목표**: 3,500 MAU, MRR $5,000
- **예산**: $500~1,000/월
- **채널**: 유료 광고 시작, 파트너십

### Month 7~12 (글로벌 확장)
- **목표**: 15,000 MAU, MRR $30,000
- **예산**: $2,000~10,000/월
- **채널**: 다국어 지원, 해외 시장 진입
