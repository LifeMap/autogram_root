## 브랜드 포지셔닝

### 포지셔닝 프레임워크

| 구성요소 | 내용 |
|---------|------|
| **타겟 오디언스** | • **1차**: 1인 크리에이터 (팔로워 5천~5만, 협찬/상품 판매)<br>• **2차**: 소규모 온라인 쇼핑몰 (직원 1~5명, Instagram 마케팅 중심)<br>• **3차**: 인플루언서/에이전시 (복수 계정 관리) |
| **시장 카테고리** | Instagram 마케팅 자동화 SaaS (댓글 → DM 전환 도구) |
| **차별점** | • **즉시성**: 댓글 달린 1초 내 자동 DM 발송<br>• **간편함**: 포스트 URL + 키워드 입력만으로 설정 완료<br>• **24/7 자동화**: 수면/주말 관계없이 무중단 작동 |
| **믿을 만한 이유** | • Instagram 공식 API 사용 (Meta 파트너)<br>• 무료 플랜 영구 제공 (월 300건)<br>• 설정 3분 내 완료 (코딩 지식 불필요) |
| **브랜드 개성** | • **효율적**: 시간 낭비 제거, 자동화 중심<br>• **친근함**: 전문가가 아닌 친구처럼 돕는 톤<br>• **신뢰**: 투명한 가격, 명확한 기능 설명 |

### 포지셔닝 선언문

> **바쁜 크리에이터와 소규모 비즈니스를 위한**
> **Instagram 댓글을 고객으로 전환할 기회를 놓치는**
> **Autogram은 댓글 기반 자동 DM 발송 서비스로서**
> **키워드 하나로 24/7 자동 응대를 제공하며**
> **수동 DM 발송이나 복잡한 챗봇 솔루션과 달리**
> **Autogram은 3분 설정, 1초 반응, 무료 플랜을 통해 누구나 쉽게 시작할 수 있습니다.**

### 레벨 3: 브랜드 기둥 (3개)

#### **기둥 1: 즉시 자동화**
**헤드라인:** "댓글이 달리면, DM이 날아갑니다"

**지원 포인트:**
- 키워드 감지 즉시 자동 DM 발송 (1초 이내)
- 24/7 무중단 모니터링 시스템
- 수동 응답 대비 20배 빠른 반응
- 주말/새벽에도 고객 놓치지 않음

**고객 혜택:**
- 📈 매출 기회 손실 방지 (자는 동안 문의 온 고객도 전환)
- ⏰ 시간 절약 (1,000개 댓글 수동 대응 16시간 → Autogram 3분)
- 💼 프로페셔널 이미지 (즉시 응답으로 브랜드 신뢰도 향상)

---

#### **기둥 2: 설정 3분, 효과는 평생**
**헤드라인:** "복잡한 건 우리가, 쉬운 건 당신이"

**지원 포인트:**
- Instagram 포스트 URL 붙여넣기만
- 키워드와 DM 메시지 입력만으로 완료
- 코딩/기술 지식 불필요
- 직관적인 한국어 UI

**고객 혜택:**
- 🚀 빠른 시작 (회원가입 → 첫 DM 발송 3분)
- 💰 외주 비용 제로 (개발자 없이 직접 운영)
- 📱 언제 어디서나 설정 가능 (모바일/데스크톱 모두 지원)

---

#### **기둥 3: 투명한 가격, 명확한 가치**
**헤드라인:** "무료로 시작하고, 성장하면 확장하세요"

**지원 포인트:**
- 월 300건 영구 무료 플랜
- 신용카드 등록 없이 시작
- 초과 시 자동 발송 중단 (과금 걱정 없음)
- 유료 플랜도 ₩5,900/월부터 (커피 2잔 값)

**고객 혜택:**
- 💳 위험 부담 제로 (카드 정보 불필요)
- 📊 ROI 검증 후 유료 전환 (무료로 충분히 테스트)
- 💸 명확한 가격 (숨겨진 비용 없음)

## 미션, 비전, 가치

### 미션 선언문
```
우리는 1인 크리에이터와 소규모 비즈니스가
Instagram 댓글을 고객으로 전환하는 과정을 자동화하여
비즈니스 성장과 고객 관계 구축에 집중할 수 있도록 돕습니다.
```

---

### 비전 선언문
```
모든 크리에이터가 자동화 도구를 통해
시간과 장소의 제약 없이 고객과 소통하고
비즈니스를 성장시키는 세상을 만듭니다.
```

---

### 핵심 가치 (4개)

#### 1. **고객 중심 자동화**
**정의:** 자동화는 고객 경험을 해치지 않고 향상시켜야 합니다.

**우리는 이것을 다음과 같이 실천합니다:**
- 스팸처럼 느껴지지 않는 자연스러운 DM 메시지 권장
- 팔로워 확인 플로우로 무분별한 발송 방지
- 고객이 원하는 정보를 정확히 전달하는 키워드 시스템

---

#### 2. **철저한 투명성**
**정의:** 가격, 기능, 제한사항을 명확히 공개합니다.

**우리는 이것을 다음과 같이 실천합니다:**
- 무료 플랜의 정확한 한도 표시 (월 300건)
- 유료 플랜 업그레이드 시점 미리 안내
- Instagram API 제한사항 사전 고지
- 서비스 장애 시 즉시 공지 및 보상

---

#### 3. **접근성 우선**
**정의:** 기술 지식이 없어도 누구나 사용할 수 있어야 합니다.

**우리는 이것을 다음과 같이 실천합니다:**
- 코딩 불필요, 클릭만으로 설정 완료
- 직관적인 한국어 UI (전문용어 최소화)
- 실시간 미리보기로 설정 결과 확인
- 친절한 가이드 및 고객 지원

---

#### 4. **지속 가능한 성장**
**정의:** 고객과 함께 성장하는 서비스를 만듭니다.

**우리는 이것을 다음과 같이 실践합니다:**
- 무료 플랜으로 충분히 테스트 후 유료 전환
- 사용량에 따른 유연한 플랜 제공
- 고객 피드백 기반 기능 개선
- 장기 고객 우대 정책 (베타 테스터 할인 등)

### 작성 스타일 가이드라인

#### ✅ 해야 할 것

- **축약형 사용**: "우리는" → "우린", "당신은" → "당신", "할 수 있습니다" → "할 수 있어요"
- **"당신"과 "귀하의" 사용**: 2인칭으로 직접 대화
- **능동태**: "우리가 DM을 발송합니다" (O) / "DM이 발송됩니다" (X)
- **짧은 문장**: 20단어 이하 유지
- **간단한 단어**: "도움" (O) / "지원" (△) / "촉진" (X)
- **예시 사용**: 추상적 개념을 구체적으로 설명
- **숫자로 구체화**: "빠릅니다" → "1초 내 발송"

#### ❌ 하지 말아야 할 것

- **전문용어**: "레버리지", "시너지", "임파워먼트" 등 비즈니스 유행어
- **모두 대문자**: "지금 바로 시작하세요!" (O) / "지금 바로 시작하세요!!!" (X)
- **수동 공격적 언어**: "아마도 알고 계시겠지만..."
- **기술 지식 가정**: "Webhook 설정" → "자동 연결 설정"
- **과장된 주장**: "세계 최고" (X) / "Instagram 자동화 전문" (O)
- **이모지 과다**: 문장당 최대 1개

- 💸 **매출 증가**: 즉시 응답으로 전환율 20% 향상
- 💰 **비용 절감**: 무료로 시작, 월 ₩5,900부터
- 📈 **데이터 기반 의사결정**: 트리거별 성과 비교
- 🏆 **프로 이미지**: 즉시 응답으로 브랜드 신뢰도 상승

| **타겟** | 크리에이터, 쇼핑몰 | 중소기업 마케터 | 에이전시 | 개인/소규모 접근성 |

### 메시징 전략

**선도할 것:**
- ✅ **Instagram 댓글 특화**: "Instagram 댓글 자동화 전문"
- ✅ **즉시성**: "1초 내 DM 발송" (경쟁사는 챗봇 플로우 따라야 함)
- ✅ **간편함**: "클릭 3번, 3분 설정" (경쟁사는 플로우 차트 그려야 함)

**직접 다룰 것:**
- ⚠️ "챗봇은 복잡하고 설정이 어렵다" → "Autogram은 클릭 3번이면 끝"
- ⚠️ "자동화는 스팸처럼 느껴진다" → "자연스러운 DM 메시지 + 팔로워 확인"

**피할 것:**
- ❌ Facebook 마케팅 기능 (ManyChat이 강함)
- ❌ 복잡한 챗봇 시나리오 (에이전시 시장은 경쟁사가 우위)
- ❌ 엔터프라이즈 기능 (우리는 개인/소규모 집중)
