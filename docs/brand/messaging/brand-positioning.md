## 브랜드 포지셔닝 프레임워크

### 타겟 오디언스

#### 1차 타겟 오디언스
**Instagram 비즈니스 사업자 (소상공인 & 중소기업)**

- **프로필:**
  - 인스타그램으로 제품/서비스를 판매하는 사업자
  - 팔로워 1,000~50,000명 규모
  - 월 평균 게시물 댓글 50개 이상
  - 댓글을 통한 문의/주문이 빈번함
  - 1인 운영 또는 소규모 팀 (2~5명)

- **주요 업종:**
  - 패션/뷰티 (의류, 액세서리, 화장품)
  - 식품/음료 (홈베이킹, 수제 음료, 밀키트)
  - 수공예품 (핸드메이드 제품)
  - 디지털 상품 (강의, 전자책, 템플릿)
  - 서비스업 (네일아트, 속눈썹, 미용)

#### 2차 타겟 오디언스
**인플루언서 & 콘텐츠 크리에이터**

- **프로필:**
  - 팔로워 10,000명 이상
  - 협찬/광고 문의가 댓글로 자주 옴
  - 팬들과의 소통 중요
  - 이벤트 진행 빈번 (응모, 경품)

**마케팅 대행사 & 소셜미디어 매니저**

- **프로필:**
  - 복수의 고객사 계정 관리
  - 효율적인 고객 응대 필요
  - 자동화 도구에 익숙함

- **주요 경쟁 카테고리:**
  - 소셜미디어 관리 도구 (Hootsuite, Buffer)
  - 챗봇/자동응답 서비스
  - CRM & 고객 관리 솔루션
  - Instagram 분석/관리 도구

- **참조 프레임:**
  - "인스타그램용 자동 응답 봇"

  - "인스타그램 고객 관리 자동화"

### 차별점 (독특한 가치 제안)

#### 핵심 차별화 요소

1. **키워드 기반 트리거 자동화**
   - 특정 키워드가 포함된 댓글에만 자동 반응
   - 예: "가격", "구매", "문의" 키워드 감지 → 자동 DM 발송
   - 스팸 방지 및 정확한 타게팅

2. **Instagram 네이티브 통합**
   - Meta 공식 API 사용 (안전하고 신뢰성 높음)
   - 계정 차단 위험 없음
   - Business 계정 공식 기능 활용

3. **무료 제공**
   - 초기 단계 완전 무료
   - 진입 장벽 제로
   - 크레딧, 사용량 제한 없음 (초기)

4. **즉시 설정 가능**
   - 5분 안에 첫 트리거 생성
   - 복잡한 설정 불필요
   - 직관적인 대시보드

**인스타그램으로 비즈니스를 운영하는 소상공인을 위한**
**댓글 문의 대응에 시간을 낭비하고 고객을 놓치는 문제가 있는**
**TWMS SNS는 Instagram DM 자동화 서비스로서**
**특정 키워드가 포함된 댓글에 자동으로 DM을 발송하여 고객 응대 시간을 90% 절감하며**
**유료 챗봇 도구나 복잡한 소셜미디어 관리 툴과 달리**
**TWMS SNS는 무료이며 5분 안에 설정 가능하고, Meta 공식 API를 사용해 안전합니다.**

## 타겟 고객 페르소나

### 페르소나 1: "바쁜 온라인 스토어 운영자 지민"

**기본 정보:**
- 나이: 29세
- 직업: 홈베이킹 사업자 (1인 운영)
- Instagram 팔로워: 3,500명
- 월 매출: 300~500만원

**일상:**
- 하루 10~20건의 댓글 문의 (가격, 배송, 커스터마이징)
- 댓글 확인하고 일일이 DM으로 응답
- 댓글 놓치면 주문 기회 상실
- 밤늦게까지 DM 응답하느라 지침

**고충 (Pain Points):**
- "댓글이 너무 많아서 놓치는 게 많아요"
- "같은 질문에 계속 답변하느라 시간 낭비"
- "밤에도 폰 확인해야 해서 스트레스"
- "자동화 도구는 비싸고 설정이 어려워요"

**목표 (Goals):**
- 고객 응대 시간 줄이기
- 모든 문의에 빠르게 응답
- 야간/주말에도 자동 응답
- 비용 부담 없이 효율성 높이기

**TWMS SNS 사용 후:**
- "가격" 키워드 댓글 → 자동으로 가격표 DM 발송
- "배송" 키워드 댓글 → 자동으로 배송 안내 DM 발송
- 하루 2시간 절약 → 제품 개발에 집중
- 고객 만족도 상승 (즉각 응답)

**고충:**
- "협찬 문의 댓글을 놓치면 수익 손실"
- "이벤트 할 때 응모 댓글 관리가 너무 힘들어요"
- "팬들 메시지에 답 못 하면 미안해요"

- 모든 협찬 문의 놓치지 않기
- 이벤트 자동화

**TWMS SNS 사용 후:**
- "협찬" 키워드 → 자동으로 협찬 문의 양식 DM
- "이벤트" 키워드 → 자동으로 참여 방법 안내
- 빠른 응답으로 팬 충성도 향상
