## 서비스 개요

### 기본 정보

| 항목 | 내용 |
|-----|------|
| **서비스명** | TWMS SNS (SNS 자동화) |
| **URL** | https://sns.twms.in |
| **카테고리** | Instagram 마케팅 자동화 SaaS |
| **핵심 기능** | 특정 키워드 포함 댓글 감지 → 자동 DM 발송 |
| **타겟 시장** | 한국 (1차), 글로벌 (2차) |
| **가격** | 무료 (초기), Freemium (6개월 후) |
| **개발 상태** | ✅ 프론트/백엔드 완료, ⏳ Meta 앱 심사 중 |

### 핵심 가치 제안

**"인스타그램 댓글, 이제 자동으로 응답하세요"**

- ⏰ **시간 절약**: 댓글 관리 시간 90% 절감
- 🎯 **기회 포착**: 24시간 자동 응답으로 고객 놓치지 않음
- 💰 **비용 절감**: 완전 무료 (초기), 유료 도구 대비 저렴
- 🚀 **간편 설정**: 5분 안에 첫 트리거 생성

## 브랜드 포지셔닝 요약

### 포지셔닝 선언문

**"인스타그램으로 비즈니스를 운영하는 소상공인을 위한, 댓글 문의 대응에 시간을 낭비하고 고객을 놓치는 문제가 있는, TWMS SNS는 Instagram DM 자동화 서비스로서, 특정 키워드가 포함된 댓글에 자동으로 DM을 발송하여 고객 응대 시간을 90% 절감하며, 유료 챗봇 도구나 복잡한 소셜미디어 관리 툴과 달리, TWMS SNS는 무료이며 5분 안에 설정 가능하고, Meta 공식 API를 사용해 안전합니다."**

### 타겟 오디언스

#### 1차 타겟
- **프로필**: Instagram 비즈니스 사업자 (소상공인)
- **규모**: 팔로워 1,000~50,000명
- **업종**: 패션/뷰티, 식품, 수공예, 디지털 상품, 서비스업
- **고충**: 하루 30개 이상 댓글, 반복 질문, 고객 놓침

#### 2차 타겟
- 인플루언서 (팔로워 10,000명+)
- 마케팅 대행사
- 소셜미디어 매니저

### 핵심 차별점

| 요소 | TWMS SNS | 경쟁 도구 |
|-----|---------|---------|
| **가격** | 무료 (초기) | $50~200/월 |
| **설정** | 5분 | 30분~수 시간 |
| **Instagram 전문화** | ✅ | ⚠️ 멀티 플랫폼 |
| **키워드 트리거** | 정교함 | 기본 수준 |
| **Meta 공식 API** | ✅ | ⚠️ 비공식 API 사용 |
| **한국어 지원** | 완벽 | 제한적 |
