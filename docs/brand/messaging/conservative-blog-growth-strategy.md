## 현실 진단

### 현재 상황
- ✅ 프론트/백엔드 개발 완료
- ⏳ Meta 앱 심사 대기 중 (2~8주 소요 예상)
- ✅ GitHub Pages 블로그 운영 중
- ⚠️ 제한된 마케팅 예산
- ⚠️ 제한된 인력 (개발자 중심)
- ⚠️ 브랜드 인지도 제로

### 핵심 제약사항
1. **시간**: 블로그 콘텐츠 작성 시간 제한 (주 5~10시간)
2. **예산**: 월 $50~200 수준
3. **채널**: GitHub Pages + Instagram 중심
4. **인력**: 1인 운영 (개발자 겸 마케터)
5. **경쟁**: 이미 성숙한 시장 (Hootsuite, Buffer 등)

### 강점
- ✅ **기술적 완성도**: 작동하는 제품
- ✅ **무료 제공**: 경쟁사 대비 가격 우위
- ✅ **Meta 공식 API**: 안전성/신뢰성
- ✅ **개발 블로그**: 기술 콘텐츠 작성 가능
- ✅ **한국어 시장**: 현지화 완벽

## GitHub Pages 블로그 전략

### 블로그 목표
1. **SEO 유입**: 검색을 통한 자연 유입 확보
2. **신뢰 구축**: 전문성 있는 콘텐츠로 신뢰도 확보
3. **전환**: 방문자를 서비스 가입자로 전환
4. **재방문**: 유용한 콘텐츠로 재방문 유도

### 콘텐츠 전략

#### 콘텐츠 믹스 (주 1~2회 발행)

**1. 가이드/튜토리얼 (40%)**
- "인스타그램 DM 자동화 완벽 가이드"
- "TWMS SNS 5분 설정 방법"
- "인스타그램 비즈니스 계정 만들기"
- "Instagram Graph API 이해하기"

**2. 사례 연구/노하우 (30%)**
- "인스타 셀러가 댓글 관리 시간을 90% 줄인 방법"
- "소상공인을 위한 Instagram 마케팅 자동화 3가지"
- "홈베이킹 사업자의 DM 자동화 사례"

**3. 비교/리뷰 (20%)**
- "Instagram 자동화 도구 비교 (무료 vs 유료)"
- "TWMS SNS vs Hootsuite vs Buffer"
- "소상공인에게 적합한 SNS 관리 도구는?"

**4. 업데이트/뉴스 (10%)**
- "TWMS SNS 신기능 소개"
- "Meta API 변경 사항 정리"
- "베타 사용자 후기 모음"

**1차 키워드 (검색량 중간, 경쟁 낮음):**

**2차 키워드 (롱테일):**
- "인스타그램 댓글 많을 때 관리 방법"
- "Instagram 비즈니스 계정 DM 자동 발송"
- "홈베이킹 인스타 댓글 관리"
- "소규모 쇼핑몰 SNS 자동화"

**3차 키워드 (초롱테일):**
- "인스타 댓글에 가격 문의하면 자동으로 DM 보내는 방법"
- "Instagram 키워드 트리거 DM 발송"

### 블로그 성장 전술

#### 1. 검색 최적화 (SEO)
- **메타 태그**: 모든 글에 title, description, keywords 최적화
- **내부 링크**: 관련 글끼리 연결 (체류 시간 증가)
- **외부 링크**: 권위 있는 사이트 인용 (신뢰도)
- **이미지 최적화**: alt 태그, 파일명에 키워드 포함
- **모바일 최적화**: 반응형 디자인 (Mobile-first)
- **페이지 속도**: 이미지 압축, CDN 사용

#### 2. 콘텐츠 배포
**블로그 글 발행 후:**
1. Instagram 스토리/피드에 공유 (요약 + 링크)
2. 네이버 블로그에 재발행 (허용 시)
3. Medium에 교차 게시 (canonical URL 설정)
4. 관련 카페/커뮤니티에 공유 (가치 제공 우선)
5. 이메일 뉴스레터 발송 (가입자 있을 경우)

#### 3. 백링크 확보
- **게스트 포스팅**: 관련 블로그에 기고 (월 1회)
- **커뮤니티 참여**: 네이버 카페, Reddit, Quora 답변에 링크
- **디렉토리 등록**: 블로그 디렉토리, 서비스 리스팅 사이트
- **인플루언서 협업**: 블로그 언급 요청

#### 4. 전환 최적화 (CRO)
- **명확한 CTA**: 모든 글 끝에 회원가입 버튼
- **랜딩 페이지**: 주요 키워드별 맞춤 랜딩 페이지
- **신뢰 신호**: 사용자 후기, 통계, 보안 인증 표시
- **간편 가입**: 소셜 로그인 (Instagram OAuth)
- **리타게팅**: 블로그 방문자 픽셀 추적 (광고 재타게팅)

## Instagram 최소 광고 전략

### 광고 목표
- **인지도**: 타겟 오디언스에게 서비스 알리기
- **트래픽**: 블로그/랜딩 페이지로 유입
- **전환**: 가입자 확보

### 광고 예산 (보수적)

| 단계 | 기간 | 월 예산 | 목표 |
|-----|------|--------|------|
| **테스트** | Month 1-2 | $50 | 광고 소재 테스트, CTR/CPC 파악 |
| **최적화** | Month 3-4 | $100 | 성과 좋은 소재 확대, ROAS 개선 |
| **확장** | Month 5-6 | $150 | 예산 증액, 새 타겟 테스트 |

**총 예산 (6개월)**: $600

### 광고 전략

#### 1. 타겟팅

**1차 타겟 (한국):**
- **위치**: 서울, 경기, 부산
- **연령**: 25~45세
- **성별**: 전체 (초기), 여성 60% (최적화 후)
- **관심사**:
  - 소규모 비즈니스 (Small Business)
  - 온라인 쇼핑몰
  - Instagram 마케팅
  - 전자상거래
  - 창업/부업
- **행동**:
  - Instagram Business 계정 운영자
  - 소규모 비즈니스 페이지 관리자
  - 최근 온라인 판매 관심 표시

**2차 타겟 (테스트):**
- 인플루언서 (팔로워 10K+)
- 마케팅 대행사 직원
- 소셜미디어 매니저

#### 2. 광고 소재

**릴스 광고 (15~30초)**

**Hook (3초):**
```
[화면] 폭발하는 댓글 알림
[자막] "하루에 댓글 30개 넘으면... 미치겠죠?"
```

**Problem (7초):**
```
[화면] 밤늦게 댓글 확인하는 모습
[자막] "댓글 놓쳐서 주문 놓친 적 있으신가요?"
[음성] "같은 질문에 일일이 답변하는 게 지겹다면?"
```

**Solution (10초):**
```
[화면] TWMS SNS 대시보드 (트리거 설정)
[자막] "이제 자동으로 DM 보내세요"
[음성] "'가격' 댓글 → 자동 가격표 발송"
[화면 전환] DM 자동 발송 모습
```

**CTA (5초):**
```
[화면] 회원가입 화면
[자막] "5분 설정, 완전 무료"
[버튼] "지금 시작하기 →"
```

**이미지 광고 (캐러셀)**

**슬라이드 1:**
```
[제목] 댓글 관리, 이제 자동으로 ⚡️
[이미지] 댓글 → DM 자동 발송 다이어그램
```

**슬라이드 2:**
```
[제목] 5분 설정, 평생 무료 💰
[이미지] 간단한 설정 화면 스크린샷
```

**슬라이드 3:**
```
[제목] 하루 2시간 절약 ⏰
[이미지] 전/후 비교 (수동 vs 자동)
```

**슬라이드 4:**
```
[제목] Meta 공식 API 사용 ✅
[이미지] 보안 인증 뱃지
[CTA] "지금 무료로 시작 →"
```

#### 3. 광고 캠페인 구조

```
캠페인 1: 인지도 (Awareness)
├── 광고 세트 1-1: 소상공인 (25-45세, 서울/경기)
│   ├── 릴스 A (문제 중심)
│   └── 릴스 B (솔루션 중심)
│
└── 광고 세트 1-2: 인플루언서 (20-35세, 전국)
    └── 캐러셀 A (기능 소개)

캠페인 2: 트래픽 (Traffic)
├── 광고 세트 2-1: 블로그 트래픽
│   ├── 이미지 광고 (가이드 포스팅 링크)
│   └── 릴스 C (데모 영상 + 블로그 링크)
│
└── 광고 세트 2-2: 랜딩 페이지
    └── 캐러셀 B (가입 유도)

캠페인 3: 전환 (Conversion)
└── 광고 세트 3-1: 리타게팅
    ├── 블로그 방문자 리타게팅
    └── 랜딩 페이지 방문 후 미가입자
```

#### 4. 성과 측정 (KPI)

| 지표 | 목표 | 비고 |
|-----|------|------|
| **CPM** | ₩3,000~5,000 | 1,000회 노출당 비용 |
| **CTR** | 1.5~3% | 클릭률 |
| **CPC** | ₩200~500 | 클릭당 비용 |
| **CPA** | ₩5,000~10,000 | 가입당 비용 |
| **전환율** | 5~10% | 클릭 → 가입 |
| **ROAS** | 1:3 이상 | 6개월 후 (유료화 시) |

#### 5. A/B 테스트 계획

**Week 1-2: 소재 테스트**
- 릴스 vs 이미지 vs 캐러셀
- 문제 중심 vs 솔루션 중심
- 짧은 영상 (15초) vs 긴 영상 (30초)

**Week 3-4: 타겟 테스트**
- 소상공인 vs 인플루언서
- 서울/경기 vs 전국
- 연령대 세분화 (25-35 vs 35-45)

**Week 5-6: 메시지 테스트**
- "시간 절약" vs "매출 증대"
- "무료" 강조 vs "간편함" 강조
- 감성적 vs 실용적

**Week 7-8: 최적화**
- 성과 좋은 조합 확대
- 저성과 광고 중단
- 예산 재분배
