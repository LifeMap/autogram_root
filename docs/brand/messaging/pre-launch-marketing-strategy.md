# TWMS SNS - 그랜드 오픈 전 사전 마케팅 전략

## 전략 개요

### 현재 상황 분석

**제품 상태:**
- ✅ Frontend/Backend 개발 완료 (프로덕션 레디)
- ✅ Meta API 부분 승인 (basic, manage_messages)
- ⏳ Meta API 댓글 권한 재심사 중 (manage_comments)
- ⏳ 정식 런칭 전 베타 단계

**목표:**
1. Meta 앱 심사 통과 지원
2. 얼리어답터 확보 (목표: 100~200명)
3. 초기 피드백 수집 및 제품 개선
4. 입소문 기반 마련
5. 런칭 모멘텀 구축

**제약 조건:**
- 대규모 유료 광고 예산 없음
- 정식 런칭 전이므로 대대적 홍보 어려움
- Meta 심사 과정 중이므로 완전한 기능 제공 불가

### 1.2 타겟 채널별 모집 전략

**타겟 해시태그:**
```

#홈베이킹 #핸드메이드 #인스타그램창업

#스마트스토어 #온라인쇼핑몰
```

**실행 방법:**
1. **계정 개설**: @twms.sns (또는 @sns.automation.kr)
2. **콘텐츠 시리즈 발행** (주 3~4회):
   - "인스타 댓글 관리 팁"
   - "자동화로 시간 절약하는 법"
   - "고객 응대 템플릿 모음"
   - Before/After 시연 영상
3. **릴스 제작**:
   - 15초 데모 영상 (키워드 감지 → 자동 DM 발송 과정)
   - 자막: "이제 댓글 일일이 확인 안 해도 돼요!"
4. **베타 테스터 모집 게시물**:
   - 캐러셀 형식 (슬라이드 5~7장)
   - 혜택 강조
   - 링크는 프로필 bio에 (linktree 사용)

**예상 도달:**
- 게시물당 도달 500~2,000명
- 전환율 2~5% → 10~100명 신청

### 2.2 피드백 수집 & 제품 개선

**피드백 채널:**

1. **주간 설문조사** (Google Form):
   - 사용 만족도 (5점 척도)
   - 가장 유용한 기능
   - 불편했던 점
   - 추가 희망 기능

2. **1:1 인터뷰** (월 5~10명):
   - Zoom/Google Meet
   - 30분 인터뷰
   - 소정의 사례 제공 (스타벅스 기프티콘)

3. **오픈채팅방 모니터링:**
   - 질문/불만 즉시 해결
   - 우수 피드백 보상

**개선 프로세스:**
- 매주 피드백 리뷰 미팅
- 우선순위 높은 이슈 즉시 수정
- 월 1회 주요 업데이트 발표
