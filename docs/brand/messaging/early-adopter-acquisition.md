# TWMS SNS - 초기 사용자(얼리어답터) 모집 전략

## 전략 개요

### 목표
- **1차 목표**: 베타 테스터 100~150명 확보 (Meta 승인용)
- **2차 목표**: 정식 런칭 시 즉시 전환 가능한 대기 목록 300~500명
- **3차 목표**: 입소문 전파자 20~30명 확보

### 핵심 전략
**"Give First, Ask Later" - 먼저 가치를 주고, 나중에 요청한다**

1. **무료 + 추가 혜택**으로 진입 장벽 제로
2. **빠른 성공 경험**으로 만족도 극대화
3. **커뮤니티 구축**으로 충성도 확보
4. **추천 보상**으로 바이럴 유도

## 얼리어답터 프로필

### 이상적인 얼리어답터 특성

**1. 문제 인식도가 높음**
- Instagram 댓글 관리에 실제 어려움을 겪는 사용자
- 하루 30개 이상 댓글 받음
- 시간 부족으로 스트레스 받음

**2. 기술 수용도가 높음**
- 새로운 도구 시도에 거부감 없음
- 자동화 도구 사용 경험 있음 (또는 관심 있음)
- Instagram Business 계정 이미 활용 중

**3. 영향력이 있음**
- 팔로워 1,000명 이상
- 커뮤니티 활동 활발
- 다른 사람에게 추천 잘함

**4. 피드백 의지가 있음**
- 적극적으로 의견 제시
- 테스트에 성실히 참여
- 개선에 관심 많음

### 우선순위 타겟

**Tier 1 (최우선):**
- 온라인 쇼핑몰 운영자 (패션, 뷰티, 수공예)
- Instagram 매출 비중 50% 이상
- 팔로워 3,000~30,000명
- 하루 댓글 50개 이상

**Tier 2:**
- 마이크로 인플루언서 (팔로워 5,000~50,000)
- 디지털 제품 판매자 (강의, 템플릿)
- 서비스업 (미용, 네일, 카페)

**Tier 3:**
- 마케팅 대행사 직원
- 소셜미디어 매니저
- 커뮤니티 운영자
