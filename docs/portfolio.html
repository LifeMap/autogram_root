SECTION 01

프로젝트 개요

SNS 마케팅 자동화 문제를 해결하는 SaaS 플랫폼

Autogram 랜딩 페이지 — "댓글이 고객이 되는 순간" 메인 슬로건과 핵심 가치 소개

서비스 소개

Autogram은 Instagram 및 Facebook 비즈니스 계정을 위한 SNS 자동화 플랫폼입니다. 핵심 기능은 댓글 트리거 기반 자동 DM 발송으로, 사용자가 특정 키워드를 댓글로 입력하면 시스템이 이를 실시간으로 감지하여 미리 설정된 DM 메시지를 자동으로 발송합니다.

인플루언서, 소상공인, 마케터들이 SNS에서 잠재 고객에게 일일이 DM을 보내는 반복적이고 시간 소모적인 작업을 완전히 자동화합니다.

해결하는 문제

  • 수동 DM 발송 불필요 — 24시간 자동 대응으로 마케팅 효율 극대화
  • 댓글 작성 직후 즉각 응답으로 고객 전환율 증가
  • Instagram/Facebook 다중 계정을 하나의 대시보드로 통합 관리
  • 트리거별 성과 측정 및 CTA 버튼 클릭 추적으로 데이터 기반 마케팅 지원
  • 한국어/영어/일본어 다국어 지원으로 글로벌 시장 대응

키워드 매칭 알고리즘 구현

/**
 * 트리거 키워드 매칭 (Instagram, Facebook 공통)
 * - 쉼표로 구분된 다중 키워드 지원
 * - 기본: 포함 매칭 (댓글에 키워드가 포함되면 매칭)
 * - '=' 접두사: 정확 매칭 (전체 일치 시에만 매칭)
 */
export const matchTriggerKeyword = (triggerWord, text) => {
  const textLower = text.toLowerCase();
  const keywords = triggerWord
    .split(',')
    .map((word) => word.trim())
    .filter((word) => word.length > 0);

  for (const keyword of keywords) {
    // 정확 매칭: '=' 접두사 사용 시
    if (keyword.startsWith('=')) {
      if (textLower.trim() === keyword.slice(1).toLowerCase()) return keyword.slice(1);
    } else {
      // 포함 매칭 (기본): 대소문자 무관
      if (textLower.includes(keyword.toLowerCase())) return keyword;
    }
  }
  return null;
};

// 요청 인터셉터: Authorization 헤더 자동 삽입
axiosInstance.interceptors.request.use((config) => {
  const token = authStore.getAccessToken();
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// 응답 인터셉터: 401 자동 토큰 갱신
axiosInstance.interceptors.response.use(null, async (error) => {
  if (error.response?.status === 401 && !originalRequest._retry) {
    originalRequest._retry = true;
    const newToken = await refreshAccessToken();  // Refresh Token 갱신
    if (newToken) return axiosInstance(originalRequest); // 재시도
    else router.push('/login');                       // 로그아웃
  }
  throw error;
});

Graceful Shutdown 구현

// SIGTERM/SIGINT 수신 시 진행 중인 요청 완료 후 안전 종료
const gracefulShutdown = (signal) => {
  server.close(() => {
    // HTTP 서버 신규 요청 중단, 기존 요청 완료 대기
    sequelize.close().then(() => process.exit(0));
  });
  // 10초 내 미완료 시 강제 종료 (데드락 방지)
  setTimeout(() => process.exit(1), 10000);
};
process.on('SIGTERM', () => gracefulShutdown('SIGTERM'));
process.on('SIGINT',  () => gracefulShutdown('SIGINT'));

프로젝트 성과 및 특장점

기술적 도전과 혁신적 해결책으로 완성한 프로덕션 수준의 SaaS

01

확장 가능한 멀티 플랫폼 아키텍처

초기 Instagram 전용 시스템을 Facebook까지 확장한 경험. tb_post_triggers.platform ENUM과 선택적 FK 설계로 플랫폼 추가 시 스키마 변경 최소화. Model-level validation으로 플랫폼 일관성 강제.

02

지능형 키워드 매칭 알고리즘

단순 포함 매칭을 넘어 = 접두사를 통한 정확 매칭 지원. 콤마 구분 다중 키워드로 하나의 트리거에 여러 조건 설정 가능. 대소문자 무관 처리(case-insensitive)로 UX 향상.

03

이중 결제 시스템 통합

국내 사용자(Iamport 빌링키)와 해외 사용자(LemonSqueezy 구독)를 동일한 구독 모델로 통합 관리. 각 결제 수단의 Webhook을 통한 실시간 구독 상태 동기화.

04

쿼터 기반 DM 제한 시스템

초과 과금 없이 한도 도달 시 차단하는 예측 가능한 과금 정책. tb_plan_properties에서 동적으로 한도를 관리하여 코드 변경 없이 플랜별 DM 한도 조정 가능.

05

랜덤 댓글 답글 로테이션

JSON 배열로 저장된 다수의 답글 템플릿 중 랜덤 선택 발송. Meta 플랫폼의 스팸 감지 알고리즘 우회 및 자연스러운 응대 경험 제공.

06

미디어 영구 보관 전략

Instagram/Facebook 미디어 URL은 만료 기한이 있어 Webhook 수신 시 S3에 자동 복사 저장. 만료 후에도 대시보드에서 게시물 이미지 확인 가능. S3 장애 시 원본 URL 폴백 처리.

07

추천인 양방향 쿠폰 시스템

추천인과 신규 가입자 모두에게 쿠폰 발급(양방향 인센티브). (user_seq, referrer_user_seq) UNIQUE 제약으로 중복 방지. 쿠폰은 보너스 DM 할당량으로 기존 쿼터에 추가.

08

Feature Flag 기반 점진적 배포

환경 변수 기반 Feature Flag 패턴으로 미완성 기능을 코드베이스에 포함하면서 특정 환경에서만 노출. Facebook 기능, 팔로워 필터 등 단계적 릴리즈 지원.

다국어 DB 스키마 설계
