## 1. 런칭 개요

### 1.1 런칭 목표

| 목표 | 수치 | 측정 방법 |
|-----|------|----------|
| **인지도** | 랜딩 페이지 방문 10,000명 | Google Analytics |
| **무료 가입** | 2,500명 | 가입 대시보드 |
| **유료 전환** | 150명 (6% 전환율) | 결제 시스템 |
| **MRR** | ₩3,000,000 | 매출 대시보드 |
| **SNS 참여** | 500 공유/댓글 | 소셜 분석 도구 |

### 1.2 타겟 오디언스 (우선순위)

**Primary (최우선):**
- 인스타그램 팔로워 1만~10만 크리에이터
- 온라인 쇼핑몰 운영자 (인스타 판매)
- 코칭/컨설팅 비즈니스

**Secondary:**
- 소규모 마케팅 에이전시
- 인플루언서 지망생
- 로컬 비즈니스 (카페, 살롱 등)
