## 1. 서비스 및 기능 분석

### 1.1 Autogram 서비스 개요

**서비스명:** Autogram
**핵심 가치:** Instagram 댓글 키워드 감지 → 자동 DM 발송
**타겟 고객:**
- Primary: 소상공인, 1인 크리에이터 (팔로워 1,000~50,000)
- Secondary: 마이크로 인플루언서, 마케팅 대행사

### 1.2 현재 요금 체계 (4단계)

| 플랜 | 월 요금 | 월간 DM | DM당 단가 | 주요 특징 |
|------|---------|---------|-----------|----------|
| **FREE** | ₩0 | 50건 | - | 테스트용, 1일 통계, CTA 미지원 |
| **MINIMUM** | ₩10,000 | 500건 | ₩20 | 1인 크리에이터, 30일 통계, CTA 지원 |
| **STARTER** | ₩15,000 | 1,500건 | ₩10 | 추천 플랜, 소규모 비즈니스 |
| **PRO** | ₩50,000 | 10,000건 | ₩5 | 대규모 운영, 90일 통계, 우선 지원 |

### 1.3 타겟 고객 페르소나

**페르소나 1: 소희 (홈베이킹 사업자, 28세)**
- Instagram 팔로워: 3,500명
- 월 평균 댓글: 150개
- 문제점: 댓글 관리 시간 부족, 팔로우 여부 확인 수동 작업
- 니즈: 팔로워에게만 DM 발송하여 전환율 높이기

**페르소나 2: 민수 (핸드메이드 악세서리, 35세)**
- Instagram 팔로워: 8,000명
- 월 평균 댓글: 300개
- 문제점: 비팔로워 DM 발송 시 신고 위험
- 니즈: 안전하게 팔로워 검증 후 메시지 전송

**페르소나 3: 지은 (마케팅 대행사, 30세)**
- 관리 계정: 10개 (각 5,000~20,000 팔로워)
- 월 평균 댓글: 1,000개
- 문제점: 클라이언트별 팔로워 관리 복잡
- 니즈: 효율적인 팔로워 필터링 자동화

## 2. 팔로우 확인 기능 상세 분석

### 2.1 기능 설명

**팔로우 확인(Follow Check) 기능**은 DM 발송 전 사용자의 Instagram 팔로우 여부를 자동으로 확인하는 기능입니다.

**작동 방식:**
1. 사용자가 키워드 댓글 작성
2. 시스템이 자동으로 팔로우 여부 확인
3. **팔로워인 경우:** 즉시 설정된 DM 발송
4. **비팔로워인 경우:** 팔로우 요청 버튼이 포함된 DM 발송
5. 사용자가 버튼 클릭 시 재확인 후 본 메시지 전송

**기술 구현:**
- Instagram Graph API 활용
- 버튼 기반 인터랙션 (Postback/Quick Reply)
- 커스터마이징 가능한 메시지 템플릿

### 2.2 고객 가치 (Value Proposition)

**1차 가치: 전환율 향상**
- 팔로워에게만 타겟팅 → 관심도 높은 고객 선별
- 예상 전환율 상승: 15~30%
- ROI 개선: 더 적은 DM으로 더 높은 매출

**2차 가치: 리스크 관리**
- Instagram 정책 준수 (스팸 방지)
- 신고 위험 감소
- 계정 정지 예방

**3차 가치: 시간 절약**
- 수동 팔로우 확인 불필요
- 자동화된 필터링
- 시간당 절약: 30~60분

**4차 가치: 브랜드 이미지**
- 팔로워 우대 → 충성도 강화
- 프리미엄 경험 제공
- 커뮤니티 구축

### 2.3 사용 시나리오

**시나리오 1: 한정판 상품 판매 (소희)**
```
상황: 홈베이킹 케이크 한정판 20개 출시
키워드: "구매", "주문"
전략: 팔로워에게만 우선 판매 기회 제공

결과:
- 비팔로워 100명 댓글 → 팔로우 유도 → 50명 전환
- 팔로워 50명 댓글 → 즉시 구매 → 20명 구매
- 전환율: 15% (기존) → 40% (팔로워)
```

**시나리오 2: 이벤트 참여 (민수)**
```
상황: 신제품 출시 기념 경품 이벤트
키워드: "응모", "참여"
전략: 팔로워만 경품 추첨 자격 부여

결과:
- 신규 팔로워 확보: +200명
- 이벤트 참여: 300명 (팔로워만)
- 브랜드 충성도 상승
```

**시나리오 3: 대행사 클라이언트 관리 (지은)**
```
상황: 10개 계정 관리, 각 팔로워 정책 다름
키워드: 계정별 상이
전략: 계정별 팔로우 정책 자동 적용

결과:
- 관리 시간 50% 절감
- 클라이언트 만족도 상승
- 추가 계정 유치 (+3개)
```

### 2.4 기술적 차별성

**경쟁사 대비 우위:**
1. **Meta 공식 API 사용** (안정성, 정책 준수)
2. **버튼 기반 UX** (클릭 한 번으로 재확인)
3. **커스터마이징** (메시지, 버튼 텍스트 수정 가능)
4. **실시간 확인** (캐싱 아닌 실시간 조회)

**기술 제약:**
- API 호출 비용 (팔로우 확인당 1회 추가 호출)
- 처리 시간 증가 (약 1~2초)
- Instagram API 제한 준수 필요

## 4. 요금 플랜 배치 전략

### 4.1 배치 옵션 분석

#### 옵션 A: 모든 플랜 포함 (무료 제공)

**장점:**
- 차별화 요소 강화
- 사용자 만족도 극대화
- 입소문 효과 (Viral)
- 경쟁사 대비 압도적 우위

**단점:**
- 수익화 기회 상실
- API 비용 부담 증가
- 프리미엄 가치 희석
- FREE 플랜 남용 가능성

**적합 시나리오:**
- 시장 점유율 우선 전략
- 초기 사용자 확보가 급할 때
- 경쟁사 견제가 필요할 때

#### 옵션 B: 유료 플랜만 포함 (MINIMUM 이상)

**장점:**
- 명확한 업그레이드 동기
- 프리미엄 기능 포지셔닝
- 수익 증대
- 비용 관리 용이

**단점:**
- FREE 플랜 매력도 감소
- 유료 전환 장벽 증가
- 경쟁사 대비 불리 (Manychat Free 1,000명)

**적합 시나리오:**
- 수익성 우선 전략
- 프리미엄 브랜드 구축
- API 비용이 높을 때

#### 옵션 C: 단계별 차등 제공 (권장)

**장점:**
- 유연한 가격 차별화
- 모든 고객층 포섭
- 업그레이드 유도 강화
- 리스크 분산

**단점:**
- 기능 관리 복잡도 증가
- 마케팅 메시지 복잡

**세부 배치:**
| 플랜 | 팔로우 확인 | 제한 | 비고 |
|------|------------|------|------|
| **FREE** | ⚠️ 제한적 | 월 10회 | 기능 체험 가능 |

### 6.1 포지셔닝 전략

## 8. 가격 심리학 관점

### 8.1 가격 프레이밍 (Price Framing)

#### 1. 앵커링 (Anchoring)

**경쟁사 가격 대비 강조:**
```
Manychat 팔로우 확인: +$29/월 (₩40,000)
Autogram MINIMUM: ₩12,000/월 (70% 저렴!)

```

**시간당 가치 환산:**
```
팔로우 확인으로 절약하는 시간: 월 10시간
시급 ₩15,000 기준 → ₩150,000 가치

MINIMUM 플랜 ₩12,000 = 12배 ROI
→ "₩12,000으로 ₩150,000 절약"
```

#### 2. 디코이 효과 (Decoy Effect)

**가격표 레이아웃:**
```
┌─────────────────────────────────────────────┐
│  MINIMUM       STARTER (추천!)     PRO      │
│  ₩12,000       ₩18,000           ₩55,000    │
│  ────────────────────────────────────────   │
│  팔로우 100회  팔로우 무제한      팔로우 무제한 │
│  DM 500건      DM 1,500건         DM 10,000건│
│               ⭐ 가장 인기!        + 전담 매니저│
└─────────────────────────────────────────────┘
```

**효과:**
- STARTER가 가장 합리적으로 보임
- MINIMUM은 너무 제한적
- PRO는 과도함
- → 70%가 STARTER 선택 유도

#### 3. 손실 회피 (Loss Aversion)

**FREE 플랜 한도 도달 시:**
```
❌ 약한 메시지:
"MINIMUM으로 업그레이드하시겠어요?"

✅ 강한 메시지:
"⚠️ 이번 달 팔로우 확인 한도 소진!
지금 놓치는 고객 = 손실되는 매출
MINIMUM으로 업그레이드하고 기회를 잡으세요."
```

**효과:**
- "얻는 것" < "잃는 것" 회피 심리
- 긴박감 조성
- 전환율 20~30% 상승

#### 4. 번들링 (Bundling)

**팔로우 확인 단독 판매 vs 플랜 포함:**
```
❌ 단독 판매 (Add-on):
- 기본 플랜: ₩10,000
- 팔로우 확인: +₩5,000
- 합계: ₩15,000

✅ 번들 포함:
- MINIMUM 플랜: ₩12,000 (전부 포함!)
- 절감: ₩3,000
```

**효과:**
- 번들이 더 가치 있어 보임
- 복잡도 감소
- 전환율 상승

### C. FAQ (예상 질문)

**Q1: 팔로우 확인이 왜 필요한가요?**
A: 팔로워에게만 DM을 보내면 전환율이 15~30% 상승하고, 신고 위험도 감소합니다.

**Q2: FREE 플랜에서도 사용 가능한가요?**
A: 네, 월 10회까지 무료로 사용 가능합니다.

**Q3: 정확도는 어느 정도인가요?**
A: Meta 공식 API를 사용하여 99.9% 정확합니다.

**Q4: 비팔로워에게는 어떤 메시지가 가나요?**
A: "팔로우하고 버튼을 눌러주세요!" 같은 커스터마이징 가능한 메시지가 발송됩니다.

**Q5: 한도를 초과하면 어떻게 되나요?**
A: FREE/MINIMUM은 발송이 중단되고, 업그레이드 안내 메시지가 표시됩니다.

**Q6: 경쟁사 대비 왜 저렴한가요?**
A: Instagram에만 집중하고, 효율적인 운영으로 비용을 절감하여 고객에게 혜택을 드립니다.

**Q7: 가격 인상 계획이 있나요?**
A: Early Adopter (첫 3개월 가입자)는 현재 가격이 평생 보장됩니다.

**Q8: 환불 정책은 어떻게 되나요?**
A: 14일 이내 100% 환불 가능합니다.

**Q9: MINIMUM과 STARTER 중 어떤 걸 선택해야 하나요?**
A: 월 100회 이상 사용하시거나, 활발한 계정이라면 STARTER를 추천합니다.

**Q10: PRO 플랜의 팔로우 전환율 분석은 무엇인가요?**
A: 팔로워 vs 비팔로워 전환율 비교, 시간대별 최적 발송 시간 등 데이터 기반 인사이트를 제공합니다.
