## 문제 해결 (Troubleshooting)

### Q1: Leonardo.ai 크레딧이 부족해요

**해결:**
- 새 계정 생성 (다른 이메일)
- Pika Labs 무료 플랜 사용
- 실제 사진 활용 (무료 스톡 사진: Unsplash, Pexels)

---

### Q2: CapCut에서 자막이 안 보여요

**해결:**
- 자막 크기 확인 (90pt 이상)
- 외곽선 추가 (가독성 향상)
- 배경에 블러 효과 추가 (Text → Background Blur)

---

### Q3: 업로드 후 음질이 나빠요

**해결:**
- Export 설정에서 "High Quality" 선택
- 음악 파일 고해상도로 다운로드
- Instagram은 자동으로 압축하므로 원본은 최고 화질로

---

### Q4: 조회수가 50도 안 돼요

**원인:**
- 계정이 새로 만들어졌거나 팔로워 0명
- 해시태그가 너무 경쟁적
- 업로드 시간이 비최적

**해결:**
- 친구/지인에게 공유 (초기 부스트)
- 소형 해시태그로 변경 (1만-10만 게시물)
- 최적 시간대에 재업로드 고려
