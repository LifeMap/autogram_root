## 1. 전략 개요

### 1.1 핵심 철학

**"감정 → 공감 → 행동"**

- **감정:** 타겟의 고통/욕구를 정확히 건드림
- **공감:** "이거 나 얘기네" 순간 창출
- **행동:** 즉각적인 저장/공유/가입 유도

### 1.2 바이럴 공식 (극초기 스타트업용)

```
바이럴 가능성 = (타겟 페인 명확도 × 해결책 즉시성 × 비주얼 임팩트) ÷ 제작 비용

목표:
- 타겟 페인 명확도: 9/10 (소상공인의 DM 지옥 공감)
- 해결책 즉시성: 10/10 (5분 설정, 즉시 사용)
- 비주얼 임팩트: 8/10 (AI 영상으로 프로페셔널한 느낌)
- 제작 비용: $0 (무료 AI 도구 활용)
```

### 1.3 타겟 오디언스 페인 포인트

| 고충 | 감정 | 빈도 | 우선순위 |
|-----|------|------|---------|
| **수동 DM 답장에 하루 2시간 소모** | 피로, 좌절 | 매일 | 🔴 최우선 |
| **댓글 놓쳐서 잠재 고객 이탈** | 불안, 죄책감 | 주 2-3회 | 🔴 최우선 |
| **밤 11시에도 DM 확인해야 함** | 스트레스 | 매일 | 🟡 중간 |
| **복사 붙여넣기 반복 작업** | 지루함 | 매일 | 🟡 중간 |
| **여러 계정 관리 지옥** | 압도됨 | 매일 | 🟢 보조 |

### 1.4 릴스 전략 원칙

**DO ✅**
- 첫 0.5초에 고통 포인트 제시 (스크롤 중지)
- 15초 이내 해결책 제시 (짧고 강렬)
- 자막 100% 활용 (소리 없이 시청)
- Before/After 명확히 대비
- CTA는 자연스럽게 (강요 금지)

**DON'T ❌**
- 제품 기능 나열 (지루함)
- 전문 용어 사용 (어려움)
- 긴 설명 (스킵됨)
- 저화질 영상 (신뢰도 하락)
- 노골적인 광고 (반감 유발)

## 2. 릴스 콘텐츠 시나리오 5개

### 시나리오 #1: "DM 지옥 탈출" (Problem-Solution)

**컨셉:** 소상공인의 하루를 극적으로 대비

**타겟 감정:** 피로, 공감, 해방감

**스토리 구조:**
```
[0-3초] Hook: "하루에 DM 100개 답장하는 소상공인의 하루"
[4-8초] Problem: 아침부터 밤까지 DM만 확인하는 모습 (빠른 편집)
[9-12초] Solution: "그런데 이 사람은 5분만 쓰고 자유로워졌어요"
[13-15초] CTA: "댓글에 '자동화' 입력하면 DM으로 링크 보내드려요" (메타!)
```

**예상 길이:** 15초

**CTA 전략:**
- 명시적: "댓글에 '자동화' 입력 → 자동 DM 발송" (서비스 직접 경험!)
- 암묵적: 저장/공유 버튼 강조

**바이럴 요소:**
- 서비스를 체험하게 만드는 CTA (참여 유도)
- Before/After 극적 대비
- 타겟이 자신의 모습을 봄

---

### 시나리오 #2: "새벽 3시의 댓글" (스토리텔링)

**컨셉:** 감성적 스토리로 공감 극대화

**타겟 감정:** 불안, 죄책감, 감동

**스토리 구조:**
```
[0-3초] Hook: "새벽 3시에 올라온 댓글 하나 때문에..."
[4-8초] Story: 다음날 아침 확인했더니 "다른 곳에서 샀어요ㅠㅠ"
[9-12초] Twist: "이제는 자는 동안에도 자동으로 DM이 가요"
[13-16초] Ending: "24시간 일하는 직원이 생긴 기분"
[17-20초] CTA: "프로필 링크에서 무료로 시작 →"
```

**예상 길이:** 20초

**CTA 전략:**
- 감정 몰입 후 자연스러운 해결책 제시
- "무료"라는 단어로 장벽 제거

**바이럴 요소:**
- 스토리 형식 (끝까지 시청 유도)
- 실제 사연 같은 진정성
- 공유 욕구 ("내 친구도 이거 겪는데")

---

### 시나리오 #3: "5계정 동시 관리법" (하우투)

**컨셉:** 구체적 솔루션 제시 (고급 타겟용)

**타겟 감정:** 호기심, 놀라움

**스토리 구조:**
```
[0-3초] Hook: "5개 인스타 계정 동시 관리하는 법"
[4-7초] Problem: 계정 전환하며 DM 확인하는 비효율
[8-15초] Solution: 대시보드 하나로 모든 계정 자동 응답 (화면 녹화)
[16-20초] Proof: "이제 하루 30분이면 끝"
[21-25초] CTA: "댓글에 '계정'이라고 쓰면 가이드 DM 드려요"
```

**예상 길이:** 25초

**CTA 전략:**
- 댓글 트리거 활용 (서비스 메타 경험)
- 가이드 제공으로 가치 우선

**바이럴 요소:**
- 멀티 계정 관리자 니치 타겟
- 화면 녹화로 신뢰도 상승
- 구체적 수치 ("30분")

---

### 시나리오 #4: "100만원 날린 실수" (경고/호기심)

**컨셉:** 부정적 경험 + 해결책 (공포 마케팅 활용)

**타겟 감정:** 공포, 안도감

**스토리 구조:**
```
[0-3초] Hook: "댓글 하나 놓쳐서 100만원 날렸어요"
[4-8초] Story: "도매 문의였는데 다음날 확인... 이미 다른 곳 계약"
[9-12초] Regret: "그때 자동 응답만 있었어도..."
[13-18초] Solution: "이제는 1분 안에 자동으로 DM이 가요"
[19-23초] CTA: "당신은 놓치지 마세요 → 프로필 링크"
```

**예상 길이:** 23초

**CTA 전략:**
- FOMO (놓치는 것에 대한 두려움) 활용
- 긴급성 강조

**바이럴 요소:**
- 충격적 제목 (100만원)
- 실수담 = 공유 가능성 높음
- 타겟이 자신의 미래를 봄

### 시나리오 #5: "인스타 마케터 vs 자동화" (비교/유머)

**컨셉:** 유머러스한 대비로 바이럴 유도

**타겟 감정:** 재미, 공감

**스토리 구조:**
```
[0-3초] Hook: "수동 DM vs 자동 DM 대결"
[4-10초] Left (수동): 정신없이 복붙하며 오타 내는 사람
[4-10초] Right (자동): 커피 마시며 여유롭게 통계 확인
[11-15초] Result: "둘 다 100명 응답 완료... 근데 시간 차이는?"
[16-20초] Reveal: "10배 차이 (2시간 vs 12분)"
[21-25초] CTA: "당신은 어느 쪽? 댓글로 알려주세요!"
```

**예상 길이:** 25초

**CTA 전략:**
- 참여형 CTA (댓글 유도)
- 대결 구도로 흥미 유발

**바이럴 요소:**
- 분할 화면 (좌우 비교)
- 유머 코드 (과장된 연기)
- 댓글 논쟁 유도 ("나는 수동이 좋은데")

### 3.3 텍스트 오버레이 제안 (CapCut 자막)

**스타일 가이드:**
- 폰트: Pretendard Bold (한글), SF Pro (영문)
- 크기: 화면의 15-20% 높이
- 색상: 흰색 텍스트 + 검은색 외곽선 (가독성 최대화)
- 애니메이션: Pop-in (튀어나오기) 또는 Slide-up (올라오기)
- 위치: 화면 중앙 또는 하단 1/3 지점

**텍스트 타이밍:**
```
Rule 1: 한 단어당 0.3초 최소 노출
Rule 2: 문장 전환 시 0.1초 여백
Rule 3: 핵심 메시지는 1.5초 이상 유지
Rule 4: 모든 음성은 자막으로 100% 표기
```

**예시 (시나리오 #1):**
```
[0-3초] "하루에 DM 100개 답장하는" → "소상공인의 하루"
[4-5초] "아침 9시" [빠르게 전환]
[6-7초] "점심 12시" [빠르게 전환]
[7-8초] "밤 11시..." [천천히]
[9-12초] "그런데 이 사람은" → "5분만 쓰고 자유로워졌어요"
[13-15초] "댓글에 '자동화' 입력 → 링크 받기"

**음악 소싱 (무료):**
1. **Instagram 음악 라이브러리** (우선 사용)
   - 저작권 문제 없음
   - 트렌드 곡 자동 추천
   - 알고리즘 노출 유리

2. **Epidemic Sound** (유료, $15/월)
   - 프로페셔널한 퀄리티
   - 저작권 걱정 없음
   - Phase 2부터 고려

3. **YouTube Audio Library** (무료)
   - 무료 음악 다양
   - 일부 곡은 크레딧 필요

**음악 볼륨 조절:**
```
Rule 1: 음성/자막이 주인 → 배경음악 30% 볼륨

### 7.2 바이럴 트리거 10가지

#### 1. 공감 트리거
```
"나 얘기네" 순간 창출
→ 구체적 상황 묘사 (일반론 금지)
예: "새벽 3시 댓글" (일반적 "댓글 관리")
```

#### 2. 호기심 트리거
```
질문으로 시작 + 답은 영상에
→ "왜 이 사람은 5분만 일할까?"
```

#### 3. 논쟁 트리거
```
양분된 의견 유도
→ "수동파 vs 자동파, 댓글로 알려주세요"
```

#### 4. FOMO 트리거
```
놓치는 것에 대한 두려움
→ "100만원 날렸어요", "기회 놓치지 마세요"
```

#### 5. 변화 트리거
```
Before/After 극적 대비
→ "하루 2시간 → 5분"
```

#### 6. 숫자 트리거
```
구체적 수치로 신뢰도
→ "100만원", "2시간", "5분", "24시간"
```

#### 7. 스토리 트리거
```
감정 몰입 유도
→ "새벽 3시의 댓글" (내러티브)
```

#### 8. 유머 트리거
```
과장되거나 재미있는 연출
→ "손목 아픔 😵", "오타 3개 ㅋㅋ"
```

#### 9. 실수 트리거
```
실패담은 공유 가능성 높음
→ "이렇게 하지 마세요", "100만원 날린 실수"
```

#### 10. 메타 트리거
```
서비스를 체험하게 만드는 CTA
→ "댓글에 '자동화' 입력 → 자동 DM" (메타!)
```

### 7.3 Hook 강화 기법

**0.5초 안에 스크롤을 멈추게 하는 Hook:**

| 유형 | 예시 | 효과 |
|-----|------|------|
| **충격적 수치** | "100만원 날렸어요" | 호기심 |
| **질문** | "하루 2시간 낭비하세요?" | 자가 진단 |
| **대비** | "이 사람 vs 저 사람" | 비교 욕구 |
| **시간** | "새벽 3시에 올라온 댓글" | 긴급성 |
| **부정** | "절대 하지 마세요" | 경고 |

**Hook 작성 공식:**
```
[감정 이모지] + [타겟 페인 구체적 묘사] + [숫자]

예시:
😭 하루에 DM 100개 답장하는 소상공인
💸 댓글 하나 놓쳐서 100만원 날렸어요
🌙 새벽 3시에 올라온 댓글 때문에
```

---

### 7.4 CTA 최적화

**좋은 CTA vs 나쁜 CTA:**

| 나쁜 CTA ❌ | 좋은 CTA ✅ |
|-----------|-----------|
| "프로필 링크 클릭하세요" | "댓글에 '자동화' 입력 → 링크 자동 발송" |
| "지금 가입하세요" | "당신은 기회 놓치지 마세요" |
| "무료로 시작" | "5분 설정으로 24시간 자유" |

**CTA 배치 타이밍:**
- 15초 이하: 마지막 2초
- 20초 이상: 마지막 5초
- 튜토리얼: 중간 + 마지막

**참여형 CTA (알고리즘 유리):**
```
"댓글로 알려주세요"
"당신은 어느 쪽? 댓글 ㄱㄱ"
"해본 사람 손들어 👋"
"공감하면 저장 ❤️"
```

| 요소 | 변수 A | 변수 B | 측정 지표 |
