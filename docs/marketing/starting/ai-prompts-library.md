## 🎨 Leonardo.ai 이미지 프롬프트

### 카테고리 A: 사람 (감정 표현)

#### A1. 스트레스/피로 (Problem 장면용)

```
A stressed Korean [small business owner / marketer / entrepreneur]
sitting at a messy desk, frantically checking [Instagram DMs / messages / notifications]
on multiple smartphones, exhausted and overwhelmed facial expression,
dark circles under eyes, messy hair, dim lighting from desk lamp,
papers and devices scattered around, warm but tense atmosphere,
shot from [above / front / side] angle at [45-degree / eye-level],
cinematic photography style, high detail, realistic, photorealistic,
--ar 9:16 --style raw --quality high
```

**사용 예:**
- Problem 장면 (Before)
- 고통 포인트 시각화
- 공감 유도

**바리에이션:**
- `multiple smartphones` → `laptop and tablets`
- `exhausted` → `frustrated` / `anxious` / `overwhelmed`
- `dim lighting` → `harsh fluorescent light`

## 📝 프롬프트 작성 팁

### 1. 구조화된 프롬프트

**기본 구조:**
```
[주제] + [상세 설명] + [감정/분위기] + [조명] + [앵글] + [스타일] + [기술 설정]
```

**예시:**
```
A stressed Korean marketer (주제)
checking multiple Instagram DMs on phones (상세)
exhausted and overwhelmed expression (감정)
dim lighting from desk lamp (조명)
shot from above at 45-degree angle (앵글)
cinematic photography style (스타일)
--ar 9:16 --quality high (기술)
```

---

### 2. 가중치 활용 (Leonardo.ai)

**문법:**
- `(keyword)` : 1.1배 강조
- `((keyword))` : 1.21배 강조
- `(keyword:1.5)` : 1.5배 강조
- `[keyword]` : 0.9배 약화

**예시:**
```
((stressed expression)), (exhausted:1.3), multiple phones, [background details]
```

---

### 3. 네거티브 프롬프트 (원하지 않는 요소 제거)

**문법:**
```
Negative Prompt:
blurry, low quality, distorted face, extra fingers, bad anatomy,
cartoon, anime, unrealistic, watermark, text overlay
```

**사용 시기:**
- 인물 생성 시 (해부학적 오류 방지)
- 고품질 이미지 필요 시
- 특정 스타일 제외 시

---

### 4. 일관성 유지 (시리즈 제작 시)

**방법:**
1. 첫 이미지 생성 후 "Seed" 번호 복사
2. 다음 이미지 생성 시 동일한 Seed 사용
3. 프롬프트 구조 동일하게 유지

**예시:**
```
이미지 1: Seed 12345 + "stressed Korean marketer..."
이미지 2: Seed 12345 + "same marketer now relaxed..."
→ 같은 인물로 일관성 유지!
```

## 🔧 문제 해결

### 문제 1: 얼굴이 이상하게 생성됨

**해결:**
```
네거티브 프롬프트 추가:
distorted face, extra fingers, bad anatomy, blurry face,
deformed, ugly, low quality

+ 추가 키워드:
photorealistic, high detail on face, professional portrait
```

---

### 문제 2: 한국인 느낌이 안 남

**해결:**
```
키워드 강조:
((Korean)), ((Asian features)), East Asian person,
Korean ethnicity, authentic Korean appearance
```

---

### 문제 3: 9:16 비율이 안 맞음

**해결:**
```
Leonardo.ai 설정:
Image Dimensions → "Portrait" 선택
또는 --ar 9:16 명시

생성 후: CapCut에서 Crop (크롭)
```

---

### 문제 4: 배경이 너무 복잡함

**해결:**
```
추가 키워드:
minimalist background, simple environment, clean backdrop,
blurred background, shallow depth of field

네거티브:
cluttered, busy background, distracting elements
```
